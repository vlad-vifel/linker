<h1 align="center">Linker</h1>

Android app for keeping links and short notes in one place and organizing them with tags. Favorites, search, tag filters and saved presets make a large collection easy to browse. Everything lives in a single local `.linker.json` file with daily backups.

## Install

Download the latest APK from the [Releases](../../releases) page and install it.
